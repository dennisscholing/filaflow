# FilaFlow v0.3.4

FilaFlow v0.3.4 adds PNG export for label-printer mobile apps.

## Changes

- The label print page now includes **Save image** next to **Print**.
- A 50 × 30 mm template exports at 584 × 354 pixels for the 300 dpi NIIMBOT B1 Pro print canvas.
- Other template sizes export at a 300 dpi equivalent resolution.
- Bulk-selected spools export one PNG file per spool.
- The selected template and monochrome setting are applied to the PNG.

No schema migration is included. Existing templates and inventory data remain unchanged.
